# Математическое обоснование метода Эйлера-Коши

## 1. Постановка задачи

Решаем задачу Коши для ОДУ первого порядка:

$$y' = f(x, y), \quad y(x_0) = y_0$$

Нам нужно найти приближённые значения $y$ в узлах сетки $x_n = x_0 + n \cdot h$.

## 2. Откуда берётся формула — интегральная форма

Проинтегрируем ОДУ на отрезке $[x_n, x_{n+1}]$:

$$y(x_{n+1}) - y(x_n) = \int_{x_n}^{x_{n+1}} f(x, y(x))\, dx$$

Отсюда точная формула:

$$y_{n+1} = y_n + \int_{x_n}^{x_{n+1}} f(x, y(x))\, dx$$

Проблема: подынтегральное выражение нам неизвестно (мы как раз ищем $y(x)$). Значит, нужно **аппроксимировать интеграл**.

## 3. Аппроксимация интеграла — правило трапеций

Применим **формулу трапеций** к интегралу:

$$\int_{x_n}^{x_{n+1}} f(x, y(x))\, dx \approx \frac{h}{2}\Big[f(x_n, y_n) + f(x_{n+1}, y_{n+1})\Big]$$

Получаем **неявный метод трапеций**:

$$\boxed{y_{n+1} = y_n + \frac{h}{2}\Big[f(x_n, y_n) + f(x_{n+1}, y_{n+1})\Big]}$$

Но здесь проблема: $y_{n+1}$ стоит и слева, и справа (внутри $f$). Это **неявная схема** — её нужно решать итерационно, что дорого.

## 4. Хитрость Эйлера-Коши: заменяем неявность на предсказание

Идея: вместо точного $y_{n+1}$ в правой части подставим **грубое приближение**, полученное обычным методом Эйлера:

**Шаг 1 — Предиктор (прогноз):**
$$\tilde{y}_{n+1} = y_n + h \cdot f(x_n, y_n)$$

Это просто шаг Эйлера — первый порядок точности, но быстрое.

**Шаг 2 — Корректор (уточнение):**
$$y_{n+1} = y_n + \frac{h}{2}\Big[f(x_n, y_n) + f(x_{n+1}, \tilde{y}_{n+1})\Big]$$

Теперь правая часть полностью известна — схема стала **явной**.

> Именно поэтому метод называют **«предиктор-корректор»**: сначала предсказали, потом уточнили.
